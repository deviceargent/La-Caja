La Caja — A Graph-Based Contextual Memory Architecture for Large Language Models

La Caja is the canonical specification repository for a graph-based contextual memory architecture for LLMs. This repository contains the official architecture documents (La Caja v2.0 and its addendum) in docs/. This initial commit establishes the specification as the canonical reference; no implementation or design decisions beyond the documents are included here.

See docs/ for the full specification files.
